# Smart CCTV (YOLOv8 + Flask)

Real-time CCTV monitoring using YOLOv8 object detection.

## Run locally
`
pip install -r requirements.txt  
python app.py  
Visit (https://smart-cctv-yolov8-arcface.onrender.com)
`
## Deploy on Render

* Connect this GitHub repo
* Build command: pip install -r requirements.txt
* Start command: python app.py
* Service type: Web Service.
